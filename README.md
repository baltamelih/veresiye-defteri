# Veresiye Defteri

Modern Flutter tabanlı veresiye takip uygulaması.

## Özellikler

- Müşteri yönetimi
- Borç / ödeme takibi
- Dashboard
- Finans raporları
- CSV export / import
- Local storage (Hive)
- Onboarding sistemi
- Splash screen
- AdMob reklam entegrasyonu
- Modern Material 3 UI

## Teknolojiler

- Flutter
- Hive
- Google Mobile Ads
- Flutter Local Notifications

## Durum

Production-ready foundation.
